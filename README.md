# Food Access and Health Outcomes Analysis

This project examines how food accessibility and socioeconomic conditions relate to obesity and diabetes across U.S. counties.

## Notebooks

- eda_visualizations.ipynb  
  Performs data cleaning, merging, and exploratory data analysis.

- modeling_analysis.ipynb  
  Implements regression and machine learning models and evaluates results.

## Data Sources

- American Community Survey (ACS)
- USDA Food Access Research Atlas
- CDC PLACES

## Key Finding

Socioeconomic factors, particularly income and poverty, are stronger predictors of health outcomes than food access alone.
